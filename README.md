# 🌐 컴퓨터네트워크 (2학년 2학기)

부천대학교 컴퓨터소프트웨어과 **컴퓨터네트워크** 수업 내용 및 주차별 과제/실습 정리 저장소입니다.

## 📁 주차별 학습 및 과제 목차

| 주차 | 주요 학습 내용 | 과제 / 실습 내용 | 상태 |
| :--- | :--- | :--- | :---: |
| **01주차** | 컴퓨터 네트워크 소개 및 개요 | 강의 오리엔테이션 & 학습 환경 구축 | 완료 |
| **02주차** | 네트워크의 구조 및 데이터 전송 방식 | 회선 교환 vs 패킷 교환 분석 | 완료 |
| **03주차** | 프로토콜과 네트워크 계층 구조 | OSI 7계층 및 TCP/IP 모델 정리 | 완료 |
| **04주차** | 응용 계층 (Application Layer) | HTTP, DNS, FTP 프로토콜 분석 | 완료 |
| **05주차** | 전송 계층 (Transport Layer) - TCP | TCP 연결 설정(3-way handshake) 및 흐름 제어 | 대기 |

| **07주차** | 네트워크 계층 (Network Layer) - IP | IPv4, IPv6 주소 체계 및 서브넷팅 | 대기 |
| **08주차** | **중간고사** | 중간 평가 | 대기 |
| **09주차** | 라우팅 알고리즘 (Routing) | 라우팅 프로토콜 및 최단 경로 알고리즘 | 대기 |
| **10주차** | 데이터 링크 계층 (Data Link Layer) | 오류 제어, 흐름 제어 및 MAC 주소 | 대기 |
| **11주차** | 스위칭 및 LAN 기술 | 이더넷(Ethernet) 및 스위치 동작 원리 | 대기 |
| **12주차** | 물리 계층 (Physical Layer) | 전송 매체 및 신호 변환 기술 | 대기 |
| **13주차** | 무선 및 모바일 네트워크 | Wi-Fi(802.11) 및 이동 통신 개념 | 대기 |
| **14주차** | 네트워크 보안 (Security) | 암호화, 방화벽, SSL/TLS 보안 프로토콜 | 대기 |
| **15주차** | **기말고사** | 기말 평가 | 대기 |
